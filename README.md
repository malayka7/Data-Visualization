# Student Performance Analysis 

##  Project Overview

Student Performance Analysis is a Python-based data visualization project that explores the relationship between students' study hours and their exam scores.

The project uses data analysis and visualization libraries to transform student data into meaningful charts, identify patterns, and communicate findings that may help teachers better understand student performance.

##  Project Objectives

* Analyze student study hours and exam scores.
* Create clear and informative data visualizations.
* Explore the relationship between study time and exam performance.
* Categorize students based on their exam scores.
* Present key statistics and insights to support better understanding and decision-making.

##  Technologies Used

* **Python** — Programming language used to develop the project.
* **Pandas** — Used to organize and analyze student data.
* **Matplotlib** — Used to create and display visualizations.
* **Seaborn** — Used to create statistical charts and improve their visual appearance.

##  Visualizations

The project includes the following visualizations:

1. **Scatter Plot:** Explores the relationship between study hours and exam scores.
2. **Bar Chart:** Compares exam scores across individual students.
3. **Histogram:** Shows the distribution of exam scores.
4. **Correlation Heatmap:** Displays the correlation between study hours and exam scores.
5. **Performance Category Chart:** Shows the number of students in each performance category.
6. **Average Score Chart:** Compares average exam scores across performance categories.
7. **Combined Dashboard:** Presents four important visualizations together for easier interpretation.

##  Key Features

* Student dataset created using Pandas.
* Automatic calculation of average, highest, and lowest exam scores.
* Calculation of average study hours.
* Performance categorization based on exam scores.
* Correlation analysis between study hours and exam scores.
* Automatic generation of visualizations.
* A data story containing key findings and recommendations.
* A combined dashboard for presenting important results.

##  Dataset

The project uses a small sample dataset containing 10 students.

The dataset includes three original columns:

* `Student` — Student name.
* `Study_Hours` — Number of hours spent studying.
* `Exam_Score` — Exam score out of 100.

A fourth column, `Performance`, is generated by the program to categorize students according to their exam scores.

### Performance Categories

| Exam Score  | Category          |
| ----------- | ----------------- |
| 80 or above | Excellent         |
| 60–79       | Good              |
| Below 60    | Needs Improvement |

These thresholds were selected for this project and are not intended to represent universal academic standards.

## Installation and Setup

### Prerequisites

Install Python on your computer before running the project.

### Step 1: Clone the Repository

After uploading the project to GitHub, clone it using:

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your actual GitHub repository URL.

Navigate to the project folder:

```bash
cd "Data Visualization"
```

### Step 2: Create a Virtual Environment

Create a virtual environment to keep the project's dependencies separate:

```bash
python -m venv .venv
```

Activate it in Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### Step 3: Install Dependencies

Install the required libraries using the requirements file:

```bash
pip install -r requirements.txt
```

### Step 4: Run the Project

Run the Python file:

```bash
python app.py
```

The program prints the student dataset, summary statistics, and key insights in the terminal. It also displays the visualizations and combined dashboard in separate windows.

Close each chart window normally to continue to the next visualization.
